# Как читать карточки

Две полки, не смешивать:

- **Ориентир** — рабочая база PLA/PETG (даташиты, типичная практика). *На этом Tornado не гоняли*, пока в карточке нет ★.
- **У нас** — только стол FlyingBear Tornado 2 Pro + Cura 5.10. Важнее гайдов. Сопло смотри в [HARDWARE.md](../printer_configs/HARDWARE.md) (сейчас 0.6 мм).

Цифры под 0.4 из чужих профилей не копировать. Ретракт «типичный Bowden 4–6 мм @ 40 мм/с» на этой машине уже тёр PLA — см. [bowden_grind.md](defects/bowden_grind.md).
