# Первый слой

Когда: не липнет, слон, углы загибает, царапины в старте.

## Ориентир

Первый слой: высота ~0.24–0.30 при сопле 0.6, скорость 15–25 мм/с, обдув 0. Стол по материалу ([pla.md](../materials/pla.md) / [petg.md](../materials/petg.md)). Линия не круглая (Z высоко) и не прозрачная плёнка (Z низко). Маленькая деталь — brim. Большая плоская подошва — часто хватает юбки. PETG: стол горячее, Z чуть выше, чем PLA.

## У нас

★ В старте всегда **G28**, затем **G29**, линии очистки X10.1 / X10.4 на Z0.28 — штатные, не выкидывать. PLA: стол 58–60, первый слой сопла 215–220. Brim 8 мм на лотосе; на большой форме с широкой подошвой юбка экономит пластик.

## Не делать

Чинить start G-code «для ровного старта». Печатать без автоуровня. Гнать первый слой со скоростью infill.
